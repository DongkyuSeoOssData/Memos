# Memos 3.2.2

화면 위에 띄워 두고 쓰는 Windows용 스티커 메모 앱입니다.
메모는 내 PC에 파일로 저장되고, 원하면 구글 드라이브로 여러 PC와 폰 사이에 동기화할 수 있습니다.

- 일반 메모와 코드 메모(문법 강조·행 번호)
- 어디서나 통하는 전역 단축키, 메모 탐색기, 빠른 검색
- 폴더로 나눠 보기, 해시태그, 즐겨찾기
- 체크리스트, 날짜·시간·반복(크론식) 알림, 이전 내용 되돌리기
- 필요한 메모에만 거는 암호 잠금
- 따로 뜨는 창 없이 메모와 탐색기 안에서 처리하는 확인·입력·설정
- 두 가지 디자인(Modern / Neo)과 라이트·다크 색 테마
- 아이폰·아이패드 등 폰 브라우저에서 같은 메모를 읽고 쓰는 모바일 화면

## 📦 배포 가이드

실행 파일(`Memos.exe`) 하나를 만들어 나눠 주는 방식입니다. 받는 사람은 파이썬을 설치할 필요가 없습니다.
Windows 전용입니다. (전역 단축키·자동 실행·중복 실행 방지가 Windows 기능을 씁니다)

### 1. 준비 (처음 한 번)

```bash
pip install -r requirements.txt
```

```bash
pip install pyinstaller
```

### 2. 배포 전 점검

```bash
python -m unittest discover -s tests
```

모두 통과하는지 확인합니다. 테스트는 임시 폴더를 쓰므로 실제 메모와 설정을 건드리지 않습니다.
이어서 소스로 한 번 실행해 화면을 직접 확인합니다.

```bash
python main.py
```

### 3. 실행 파일 만들기

실행 중인 Memos가 있으면 먼저 종료합니다(트레이 아이콘 우클릭 → 종료). 그다음 프로젝트 폴더에서 실행합니다.

```bash
pyinstaller Memos.spec
```

- 결과물은 `dist/Memos.exe` 하나입니다. 아이콘 등 필요한 파일이 모두 이 안에 들어 있습니다.
- `build` 폴더는 만드는 중에 쓰는 임시 폴더라 지워도 됩니다.
- 소스나 아이콘을 바꿨으면 다시 만들어야 반영됩니다.
- 만든 `Memos.exe`를 실행해 트레이 아이콘이 뜨고 메모가 열리는지 확인한 뒤 배포합니다.

### 4. 나눠 주기와 설치

`Memos.exe`만 전달하면 됩니다. 받는 사람은 원하는 폴더에 두고 실행합니다.

- **처음 실행할 때 Windows 경고:** 서명하지 않은 실행 파일이라 "Windows의 PC 보호" 창이 뜹니다. `추가 정보` → `실행`을 누르면 됩니다. 이 경고는 설치 파일로 만들어도 똑같이 뜨며, 없애려면 코드 서명이나 Microsoft Store 배포가 필요합니다.
- **실행하면** 시스템 트레이에 아이콘이 생깁니다. 아이콘을 누르면 메모 탐색기가 열리고, 우클릭하면 새 메모·정렬·동기화·환경설정·종료 메뉴가 나옵니다.
- **Windows를 켤 때 자동으로 실행**하려면 환경설정 → 일반에서 `윈도우 시작 시 자동 실행`을 켭니다.
- **두 번 실행해도 하나만 뜹니다.** 이미 실행 중이면 그 앱의 탐색기가 열립니다.

### 5. 새 버전으로 바꾸기

1. 실행 중인 Memos를 종료합니다. (트레이 아이콘 우클릭 → 종료)
2. `Memos.exe`를 새 파일로 덮어씁니다.
3. 다시 실행합니다.

메모와 설정은 실행 파일과 따로 저장되므로 그대로 유지됩니다. ([데이터가 저장되는 곳](#-데이터가-저장되는-곳))

`Memos.exe`를 다른 폴더로 옮겼다면, 환경설정의 `윈도우 시작 시 자동 실행`을 껐다가 다시 켜 주세요. 자동 실행은 실행 파일의 위치를 기억하기 때문입니다.

### 6. 동기화·모바일 화면 배포

구글 드라이브 동기화와 폰 화면은 구글 앱스 스크립트에 올려서 씁니다. PC 앱과는 따로 배포합니다.

- 처음 설정: [구글 드라이브 동기화 → 설정 방법](#설정-방법)
- `mobile/Code.gs`나 `mobile/Index.html`을 고쳤을 때: 스크립트 편집기에 새 내용을 붙여 넣고 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포합니다. 저장만으로는 반영되지 않습니다. "새 배포"를 누르면 주소가 바뀌니 주의하세요.

## ✨ 주요 기능

### 처음 실행했을 때

메모가 하나도 없는 상태로 처음 실행하면(동기화를 아직 설정하지 않은 PC에서) **사용 안내 메모 세 개**(① 메모 사용법, ② 메모 탐색기 사용법, ③ 환경설정과 동기화)가 `사용 안내` 폴더에 만들어지고, ①이 화면에 열립니다. 읽은 뒤에는 지우면 되고 다시 만들어지지 않습니다. 다시 보고 싶으면 환경설정 → 일반 설정 → `사용 안내 메모 만들기`를 누릅니다.

### 메모 창

- **일반 메모:** 굵게·기울임·밑줄·취소선, 글꼴·크기, 글자색·형광펜(사용자 지정색 포함), 불릿·번호 목록, 체크리스트, 들여쓰기를 지원합니다.
- **코드 메모:** 문법 강조, 행 번호, 다크/라이트 코드 테마, 자동 정렬(Prettify)을 지원합니다.
  지원 언어는 JSON, C#, VB.NET, Power Automate, PowerShell, Batch, SQL, Markdown, Python, JavaScript, HTML, CSS, C++, Java입니다.
- **글꼴과 크기:** 칸에는 직접 적고(글꼴은 이름의 일부로 검색, 크기는 6~72 숫자), 칸 오른쪽의 `▾` 버튼으로는 목록을 펼칩니다. 목록이 펼쳐진 상태에서도 칸에 적으면 그 글자가 들어간 것만 남습니다.
- **접기(롤업):** 제목 줄만 남기고 얇게 접습니다. 접은 메모는 화면 아래에 가지런히 쌓을 수 있습니다.
- **위치와 크기 기억:** 접힌 상태와 펼친 상태는 위치와 크기를 서로 따로 기억합니다. 접으면 접어 두었던 자리와 너비로, 펴면 펼쳐 두었던 자리와 크기로 돌아가며, 한쪽에서 옮기거나 크기를 바꿔도 다른 쪽은 달라지지 않습니다. 처음 접는 메모는 화면 가장자리에 가까운 모서리를 기준으로 접힙니다.
- **쌓아 둔 접은 메모 펴기:** 펼칠 자리가 한 줄로 쌓아 둔 다른 접은 메모를 가리게 되면, 가리지 않도록 쌓인 줄 옆(왼쪽에 쌓였으면 오른쪽, 오른쪽에 쌓였으면 왼쪽)에 펼쳐집니다.
- **고정(핀):** 다른 창 위에 항상 띄웁니다.
- **메모별 색·불투명도:** 메모마다 바탕색과 불투명도를 따로 정합니다.
- **찾기/바꾸기, 한/영 오타 변환, 전체 복사**를 메모 안에서 바로 씁니다.
- **옆에 붙어 열리는 화면:** 알림 설정과 이전 내용은 메모 오른쪽(자리가 없으면 왼쪽)에 붙어서 열립니다. 메모와 같은 색으로 이어져 한 덩어리처럼 보이고, 메모가 작거나 접혀 있어도 화면 전체가 보입니다.
- **메모 안에서 묻기:** 암호 입력과 색 고르기는 본문을 흐리게 가리고 메모 한가운데에서 묻습니다. 메모가 너무 작으면 같은 방식으로 옆에 붙어서 묻습니다.

### 목록과 들여쓰기

- 불릿·번호 목록은 버튼으로 켜고 끕니다. 선택한 줄에만 적용되고, 같은 버튼을 다시 누르면 그 줄만 목록에서 빠집니다.
- 목록 항목에서 `Tab`을 누르면 하위 목록이 되고, `Shift+Tab`을 누르면 원래 목록으로 돌아옵니다.
- 여러 줄을 선택해 `Tab` / `Shift+Tab`을 누르면 줄마다 한 단계씩 들여쓰고 내어 씁니다.
- 코드 메모의 `Tab`은 실제 공백 4칸입니다. 복사해도 들여쓰기가 유지됩니다.
- 입력 중 자동으로 목록으로 바꾸는 기능은 일부러 넣지 않았습니다. 필요할 때 버튼으로 켭니다.

### 자동 저장과 수정일시

- 마지막 입력 후 일정 시간(기본 1분) 동안 입력이 없으면 저장합니다.
- 계속 입력 중이어도 10분에 한 번은 저장합니다.
- 메모를 닫거나 앱을 종료할 때, 그리고 `Ctrl+S`를 누르면 바로 저장합니다.
- **수정일시는 본문이나 제목을 실제로 고쳤을 때만 바뀝니다.** 메모를 열어 보기만 하거나, 고친 것 없이 저장하거나, 창을 옮기고 접거나, 폴더를 옮기고 즐겨찾기·색을 바꾸는 것으로는 바뀌지 않습니다. (폴더·즐겨찾기·색 변경은 수정일시와 별개로 다른 기기에 동기화됩니다)

### 메모 탐색기

- 모든 메모를 표로 보고, 제목·내용으로 검색합니다.
- **제목 줄:** 왼쪽에 폴더 버튼과 라이트/다크 버튼, 가운데에 `Memos`, 오른쪽 끝에 창 버튼(고정·최소화·최대화·닫기)이 있습니다.
- **필터:** 전체 / 일반 / 코드, 그리고 해시태그.
- **해시태그:** 본문에 `#회의`처럼 쓰면 태그 목록에 나타납니다. 낱말 첫머리의 `#`만 태그로 보고, 색상 코드(`#FFFFFF`)와 코드 메모는 제외합니다.
- **즐겨찾기(★):** 즐겨찾기한 메모가 목록 맨 위에 옵니다.
- **제목 옆 표시:** 알림이 걸린 메모는 `⏰`, 암호 메모는 `🔒`가 제목 앞에 붙고, 체크리스트가 있는 메모는 제목 뒤에 진행 표시(`☐ 2/5`)가 붙습니다.
- **여러 개 고르기:** 줄 맨 앞의 체크 상자를 하나씩 눌러 여러 메모를 고릅니다. `Ctrl`·`Shift`를 누른 채 줄을 눌러 고르면 그 줄들이 체크됩니다. 맨 위 `선택` 머리글을 누르면 전체를 고르거나 풉니다. 체크는 목록이 다시 그려져도 유지되고, 휴지통 보기로 바꾸면 풀립니다.
- **여러 개 지우기:** 고른 뒤 `삭제` 버튼이나 `Delete` 키를 누르거나, 고른 줄 중 하나에서 우클릭 → `선택한 N개 삭제`를 누릅니다. 확인 화면에 지워질 메모의 제목이 보입니다. 체크한 것이 없으면 지금 선택한 줄의 메모가 대상입니다.
- **미리보기:** 메모를 열지 않고 아래 칸에서 바로 읽고 고칩니다. 체크 상자도 눌러서 체크할 수 있고, 이때는 서식이 있는 메모도 서식이 그대로 남습니다. 미리보기에서 글자를 고치면 서식 없는 텍스트로 저장되며, 서식이 있는 메모였다면 그 사실을 알려 줍니다.
- **미리보기 우클릭:** 메모 열기, 체크리스트 켜기/끄기, 복사·붙여넣기·모두 선택, 전체 내용 복사, 알림 설정, 이전 내용 보기가 나옵니다. 잠긴 메모에서는 잠금 해제만 나옵니다.
- **환경설정 버튼:** `미리보기` 글자 왼쪽의 톱니바퀴를 누르면 환경설정이 탐색기 옆에 펼쳐지고, 다시 누르면 닫힙니다. → [환경설정](#-환경설정)
- **보호(잠김):** 실수로 지우지 않도록 삭제를 막습니다. 암호 잠금과는 별개입니다.
- **휴지통:** 지운 메모는 휴지통으로 가고, 복원하거나 비울 수 있습니다. 보관 기간이 지나면 자동으로 지우게 할 수도 있습니다.
- **줄 우클릭 메뉴:** 열기, 즐겨찾기, 보호, 암호 관리, 알림 설정, 이전 내용 보기, 폴더로 이동, 색 변경, 복사, 삭제.
- **탐색기 안에서 묻기:** 삭제 확인, 폴더 이름 입력, 탐색기에서 부르는 알림 설정·암호 입력은 따로 창을 띄우지 않고 탐색기 가운데에서 묻습니다.
- **너비:** 폴더 이름이 길거나 폴더가 많아도 탐색기를 넓히지 않습니다. 긴 이름은 줄여(…) 보여 주고, 많은 탭은 `<` `>`로 넘겨 봅니다.

### 폴더

메모를 폴더로 나눠 관리합니다. 처음에는 `개인`, `업무` 두 폴더가 있고, 원하는 대로 더 만들 수 있습니다.

- **폴더 고르기:** 탐색기에서 폴더를 고르는 화면은 세 가지 중에서 정할 수 있습니다. (환경설정 → 일반 설정 → 폴더 표시 방식)

  | 방식 | 모습 | 맞는 경우 |
  |---|---|---|
  | 탭 줄 (기본) | 위쪽에 `전체 메모 · 개인 · 업무 · 미분류 · ＋`가 한 줄로 놓입니다. 하위 폴더가 있는 폴더를 고르면 바로 아래에 하위 폴더 줄이 나타납니다. 한 줄에 다 들어가지 않으면 양 끝에 `<` `>` 버튼이 생기고, 버튼이 잘리지 않게 들어가는 만큼씩 넘겨 봅니다. | 폴더가 몇 개 안 될 때 |
  | 사이드바 | 제목 줄의 폴더 버튼(지금 고른 폴더 이름이 적혀 있음)을 누르면 탐색기 왼쪽에 폴더 목록 패널이 덧붙습니다. 탐색기 본래 화면은 버튼 위치와 크기, 글자 크기가 그대로이고 창만 왼쪽으로 그만큼 넓어집니다. 폴더마다 메모 개수가 보입니다. | 폴더가 많거나 여러 단계일 때 |
  | 드롭다운 | 제목 줄의 버튼 하나를 눌러 고릅니다. 맨 위에 `＋ 새 폴더`, 그다음 `전체 메모`, 그 아래에 폴더가 놓입니다. | 자리를 아끼고 싶을 때 |

  어느 방식이든 `전체 메모`는 모든 메모를, `미분류`는 폴더가 없는 메모만 보여 줍니다.
- **고른 폴더 안에서만 동작:** 폴더를 고르면 목록, 메모 개수, 해시태그 목록, 검색이 모두 그 폴더의 메모만 대상으로 합니다.
- **하위 폴더:** 이름을 `업무/프로젝트A`처럼 `/`로 구분하면 하위 폴더가 됩니다. `업무`를 고르면 그 아래 폴더의 메모도 함께 보입니다.
- **메모 옮기기:** 메모를 우클릭 → `폴더로 이동`. 체크해 둔 메모가 있으면 함께 옮깁니다.
- **새 메모:** 폴더를 골라 둔 상태에서 만든 메모는 그 폴더에 들어갑니다. (전역 단축키로 만들 때도 같습니다)
- **폴더 관리:** 탭 줄은 `＋`와 탭 우클릭, 사이드바는 `＋ 새 폴더`와 항목 우클릭, 드롭다운은 목록의 메뉴에서 새 폴더·이름 바꾸기·삭제를 합니다. 폴더를 삭제해도 메모는 지워지지 않고 미분류로 옮겨집니다.
- **여러 폴더 삭제:** 같은 메뉴의 `여러 폴더 삭제`를 고르면 폴더 목록이 체크 상자와 함께 뜹니다. 지울 폴더를 체크하면 한 번에 지워지고, 상위 폴더를 체크하면 하위 폴더도 함께 지워집니다.
- **폴더 순서:** 폴더는 만든 순서대로 놓입니다. 탭 줄에서는 탭을 좌우로, 사이드바에서는 항목을 위아래로 끌어서 순서를 바꿀 수 있고, 바꾼 순서는 기억되어 드롭다운에도 그대로 적용됩니다. 하위 폴더는 항상 자기 상위 폴더 아래에 모여 있으며 그 안에서만 순서가 바뀝니다.
- **저장되는 곳:** 폴더는 디스크의 실제 폴더가 아니라 메모에 붙는 분류 이름입니다. 메모 파일은 폴더와 상관없이 모두 메모 저장 폴더 한곳에 있고, 각 메모 파일 안에 어느 폴더에 속하는지가 적혀 있습니다.
- **동기화:** 메모가 어느 폴더에 있는지, 그리고 폴더 목록과 순서가 다른 PC와 폰에 동기화됩니다. 빈 폴더도 함께 보입니다.

### 체크리스트

줄 맨 앞에 체크 상자를 두고 눌러서 체크합니다. 메모 창과 탐색기 미리보기에서는 네모 상자로 그려지고, 끝낸 줄은 흐리게 바뀌며 취소선이 그어집니다. 저장은 `☐` / `☑` 글자로 하므로 저장 형식이 바뀌지 않고, 폰 화면과 검색에서는 그 글자로 보입니다.

- **붙이기/떼기:** 서식 줄의 체크 상자 버튼이나 `Alt+K`를 누르면 커서가 있는 줄(여러 줄을 골랐으면 그 줄들)에 체크 상자가 붙습니다. 모두 체크리스트 줄일 때 누르면 상자를 뗍니다.
- **체크하기:** 상자를 마우스로 누르면 `☐` ↔ `☑`로 바뀝니다.
- **이어 쓰기:** 체크리스트 줄 끝에서 `Enter`를 치면 다음 줄도 상자로 시작합니다. 상자만 있는 빈 줄에서 `Enter`를 치면 상자가 지워지고 체크리스트가 끝납니다.
- **지우기:** 상자 바로 뒤에서 `Backspace`를 누르면 상자와 그 뒤의 공백이 한 번에 지워집니다. (불릿·번호 목록과 같은 방식)
- **미리보기에서 체크:** 탐색기의 미리보기에서도 상자를 눌러 체크할 수 있습니다.
- **진행 표시:** 체크리스트가 있는 메모는 제목 줄에 끝낸 일/전체가 보입니다. 남은 일이 있으면 `☐ 2/5`, 다 끝내면 `☑ 5/5`입니다. 메모를 접어도 보이고, 탐색기에서는 제목 뒤에 같은 모양으로 보입니다.

### 알림

메모에 날짜와 시간을 정해 알림을 겁니다. 메모 창의 우클릭 메뉴나 `Ctrl+R`, 탐색기의 우클릭 메뉴에서 **알림 설정**을 고릅니다. 메모 창에서 부르면 그 메모의 오른쪽에 설정 화면이 붙어서 열립니다. 메모와 같은 색으로 이어져 한 덩어리처럼 보이고, 메모가 작거나 접혀 있어도 설정 화면 전체가 보입니다. 탐색기에서 부르면 탐색기 안에 나타납니다.

- **시간 입력:** 시와 분을 숫자로 바로 적습니다. 시를 적으면 분 칸으로 넘어갑니다. `24시간`을 끄면 `오전`/`오후` 버튼으로 나눠 적고(15처럼 적으면 오후 3시로 바꿔 줌), 켜면 0~23시로 적습니다. 고른 방식은 기억되며 알림 시각을 보여 주는 곳에도 같은 방식(`오후 3:30` 또는 `15:30`)이 쓰입니다.
- **한 번만:** 날짜는 달력에서 고르고 시간을 적거나, 빠른 선택 버튼 세 개(기본 `10분 뒤`, `30분 뒤`, `1시간 뒤`)를 누릅니다. 이 세 버튼의 시간은 환경설정 → 일반 설정 → **알림 설정의 빠른 선택**에서 바꿉니다.
- **반복:** `반복`을 체크하면 반복 방식을 고를 수 있고, 고른 방식에 필요한 입력만 보입니다. 아래쪽에 다음 세 번의 알림 시각을 미리 보여 줍니다.

  | 반복 방식 | 입력하는 것 |
  |---|---|
  | 매일 | 시간 |
  | 평일마다 (월~금) | 시간 |
  | 매주 | 요일(여러 개 고를 수 있음), 시간 |
  | 매월 | 날짜(여러 개 고를 수 있음), 시간. 29~31일처럼 그 달에 없는 날짜는 그 달의 마지막 날에 울립니다. |
  | 크론식 | 크론식 |

- **크론식:** `분 시 일 월 요일` 다섯 칸을 씁니다. `*`, 목록(`1,15`), 범위(`1-5`), 간격(`*/15`)을 쓸 수 있고 요일은 0(일)~6(토)이며 7도 일요일입니다. 창에 칸 설명과 예시가 함께 나오고 예시를 누르면 그대로 입력됩니다. 틀린 식은 저장되지 않습니다.

  | 식 | 뜻 |
  |---|---|
  | `0 9 * * 1-5` | 평일 오전 9시 |
  | `30 18 * * 5` | 매주 금요일 오후 6시 30분 |
  | `0 10 1 * *` | 매월 1일 오전 10시 |
  | `0 9,14 * * *` | 매일 오전 9시와 오후 2시 |
  | `*/30 9-18 * * 1-5` | 평일 9시~18시대에 30분마다 |

- **알림이 울리면:** 화면 오른쪽 아래에 알림 창이 뜹니다. (Windows 알림은 따로 띄우지 않습니다) `메모 열기`, `완료`, 또는 `10분`·`1시간`·`내일`로 미루기를 고릅니다. 반복 알림을 미뤄도 원래 일정은 그대로입니다.
- **표시:** 알림이 걸린 메모는 서식 줄 오른쪽에 알림 시각이 보이고(누르면 바꾸기), 탐색기 제목 앞에 `⏰`가 붙습니다.
- **앱이 꺼져 있었다면:** 그 사이 지나간 알림은 앱을 켰을 때 한 번 울립니다. 반복 알림은 놓친 횟수만큼 울리지 않고 한 번만 울린 뒤 다음 시각으로 넘어갑니다.
- **암호 메모:** 알림 창에 제목과 `🔒 암호 메모` 표시만 보이고 본문은 보이지 않습니다. 메모가 열려 있는 중이어도 마찬가지입니다.
- **동기화:** 알림은 메모와 함께 동기화되므로, 같은 메모를 쓰는 PC가 여러 대 켜져 있으면 각 PC에서 울립니다. 폰에서는 알림이 걸린 시각을 볼 수 있지만 폰이 울리지는 않습니다.

### 이전 내용 (변경 기록)

메모를 고쳐 저장할 때마다 그 전의 내용을 남겨 두었다가 되돌릴 수 있습니다. 메모 창의 우클릭 메뉴나 `Ctrl+Shift+H`, 탐색기의 우클릭 메뉴에서 **이전 내용 보기**를 고릅니다. 메모 창에서 부르면 그 메모의 오른쪽에 붙어서 열립니다. 처음에는 기록 목록(저장 시각과 제목)만 보이고, 하나를 누르면 그 옆에 본문과 `이 내용으로 되돌리기` 버튼이 펼쳐집니다.

- 메모마다 최근 20개까지 남깁니다. 계속 고치는 중에는 10분에 한 번만 남깁니다.
- 동기화로 다른 기기의 내용을 받아 덮어쓸 때는 덮어쓰기 직전의 내용을 항상 남깁니다.
- 되돌리면 되돌리기 직전의 내용도 기록에 남으므로 다시 돌아올 수 있습니다.
- 즐겨찾기·색·폴더·알림만 바꾼 경우에는 기록을 남기지 않습니다.
- **암호 메모의 기록은 암호문으로만 남습니다.** 메모에 암호를 걸면 그때까지 쌓인 기록도 같은 암호로 잠기고, 암호를 바꾸면 기록도 새 암호로 다시 잠깁니다. 암호를 없애면 기록도 함께 풀립니다.
- **암호 메모의 기록 보기:** 메모가 열려 있으면 기록 내용이 바로 보입니다. 메모가 잠겨 있으면 암호를 넣어야 보입니다.
- **되돌려도 잠금 상태는 그대로입니다.** 암호 메모는 되돌린 뒤에도 지금 암호로 잠긴 암호 메모이고, 일반 메모는 일반 메모로 남습니다. 암호 메모는 잠금을 푼 상태에서만 되돌릴 수 있습니다. 다른 암호로 잠겼던 오래된 기록은 그때 쓰던 암호를 넣어야 보거나 되돌릴 수 있습니다.
- 기록은 이 PC에만 두며 동기화하지 않습니다. 메모를 휴지통에서 완전히 지우면 기록도 함께 지워집니다.

### 빠른 검색

`Alt+Q`(전역 단축키)나 트레이 메뉴의 **빠른 검색**으로, 다른 프로그램을 쓰는 중에도 화면 위쪽에 검색 창을 띄웁니다.

- 글자를 치는 대로 제목·본문·폴더 이름에서 찾습니다. 낱말을 띄어 쓰면 모두 들어 있는 메모만 나옵니다.
- 제목이 맞는 메모가 먼저, 그다음 본문이 맞는 메모가 최근에 고친 순으로 나옵니다. 아무것도 치지 않으면 최근에 고친 메모가 보입니다.
- `↑` `↓`로 고르고 `Enter`로 엽니다. `Esc`를 누르거나 다른 창을 누르면 닫힙니다.
- 암호 메모는 잠겨 있든 열려 있든 제목으로만 찾습니다.

### 창 다루기

- **가장자리에 붙기:** 메모 창과 탐색기를 화면 가장자리 가까이 끌면 자석처럼 딱 붙습니다. `Ctrl`을 누른 채 끌면 붙지 않습니다.
- **화면 안에 머무름:** 탐색기는 모니터의 작업 영역 밖으로 끌려 나가지 않고, 그 모니터의 화면보다 크게 늘어나지 않습니다. 다른 모니터로 옮기는 것은 됩니다.
- **글자 크기:** 탐색기는 `Shift+휠`, 메모 본문은 `Ctrl+휠`로 조절합니다.
- **정렬:** 펼친 메모와 접은 메모를 각각, 메모가 놓인 모니터 안에서 가지런히 정렬합니다.
- **창을 따로 띄우지 않음:** 확인·이름 입력·암호·색 고르기는 부른 창(메모·탐색기) 안에서 묻습니다. 알림 설정과 이전 내용은 메모 옆에 붙어서 열리고, 환경설정은 탐색기 옆에 펼쳐집니다. 따로 뜨는 것은 휴지통 복원 비교, 여러 폴더 삭제, 탐색기에서 부른 이전 내용, 알림이 울릴 때의 알림 창, 빠른 검색 정도이고, 이것들도 Windows 기본 창이 아니라 앱과 같은 모양입니다. 파일·폴더를 고르는 창만 Windows의 것을 그대로 씁니다.
- **알림은 토스트로:** "저장했습니다" 같은 알림은 창을 따로 띄우지 않고, 그 일이 일어난 곳(메모·탐색기·환경설정) 안의 토스트로 보여 줍니다.

## 🔒 암호 메모

앱 전체에 거는 암호는 없습니다. 숨기고 싶은 메모에만 암호를 겁니다.

- **거는 법:** 메모 창 또는 탐색기에서 우클릭 → `이 메모에 암호 걸기`, 또는 `Ctrl+Shift+L`.
- **암호 입력:** 따로 창이 뜨지 않고 메모 창 한가운데에서 묻습니다. 본문이 흐려지고 그 위에 암호 칸이 나타나며, 틀리면 칸 아래에 바로 알려 줍니다. 잠긴 메모는 본문 자리가 가려져 있고 그 가운데의 암호 칸에 암호를 적어 엽니다.
- **접어 둔 암호 메모:** 제목 왼쪽에 자물쇠가 보여 암호 메모임을 알 수 있습니다.
- **잠긴 메모의 크기:** 잠긴 메모는 암호 칸이 가운데에 넉넉히 들어가는 크기(340×290)로 뜨고, 암호를 넣으면 원래 크기로 돌아갑니다. (잠긴 동안의 크기는 메모의 크기로 기억하지 않습니다)
- **잠긴 메모 열기:** 탐색기에서 잠긴 메모를 열면 접어 둔 메모는 접힌 그대로, 펼쳐 둔 메모는 펼쳐진 그대로 열립니다. 열 때 암호를 따로 묻지 않으며, 접힌 메모는 펼치면 암호 칸이 나타납니다. 탐색기에서 잠그거나 풀 때는 탐색기 안에서 묻습니다.
- **암호화:** 본문은 그 메모의 암호에서 PBKDF2(SHA-256, 60만 회)로 만든 키로 AES-256-GCM 암호화됩니다. 디스크와 구글 드라이브 모두 암호문으로 저장됩니다.
- **암호화되지 않는 것:** 제목, 색, 폴더, 수정 시각은 암호화되지 않습니다. 암호 메모에도 민감한 내용은 제목에 쓰지 마세요.
- **자동 잠금:** 암호를 입력해 연 메모는 마지막 입력 후 일정 시간(기본 5분)이 지나면 다시 잠깁니다. 창을 닫아도 바로 잠깁니다.
- **암호를 잊으면:** 관리자 복구 키를 설정해 두지 않았다면 복구할 수 없습니다.

### 관리자 복구 키 (선택)

암호를 잊은 메모를 관리자가 열 수 있게 하는 장치입니다. 공개키 방식이라 저장소에 올라가는 것은 공개키뿐이고, 공개키로는 메모를 열 수 없습니다.

```bash
python tools/generate_master_key.py
```

- 공개키는 `core/master_public_key.py`에 기록됩니다. 저장소에 올려도 안전합니다.
- 개인키는 암호로 보호된 `.pem` 파일로 저장소 밖(기본 `~/memoit_master_private_key.pem`)에 만들어집니다. **이 파일은 저장소에 올리지 마세요.** (`*.pem`은 `.gitignore`에 들어 있습니다)
- 키를 만든 뒤에 잠그는 메모부터 복구 대상이 됩니다. 그 전에 잠근 메모는 암호를 한 번 다시 설정해야 합니다.
- 공개키가 실행 파일에 들어가야 하므로, 키를 만든 뒤에는 실행 파일을 다시 만들어 배포합니다.
- 복구: 잠긴 메모 우클릭 → `관리자 키로 복구…` → 개인키 파일과 그 암호를 넣고 새 암호를 정합니다.

## ☁ 구글 드라이브 동기화

동기화는 선택 사항입니다. 켜지 않으면 메모는 이 PC에만 저장됩니다.

### 동작 방식

- **바뀐 것이 있을 때만, 바뀐 것만 주고받습니다.** 정해진 간격마다 무조건 동기화하지 않습니다. 메모 내용이 바뀌면 그때부터 설정한 시간만큼 기다렸다가 바뀐 메모만 올리고, 드라이브에서는 지난번 이후 바뀐 파일만 내려받습니다. 창을 옮기거나 접는 것처럼 다른 기기와 상관없는 변화는 동기화를 일으키지 않습니다.
- **기다리는 시간:** 변경 후 동기화까지 1분 / 10분 / 30분 / 1시간 중에서 고릅니다. 기다리는 동안 더 고친 것도 한 번에 올립니다. 탐색기의 동기화 버튼이나 트레이 메뉴를 누르면 바로 동기화합니다.
- **다른 기기의 변경 확인:** 이 PC에서 고친 것이 없을 때는 15분마다 드라이브의 파일 목록만 한 번 확인해, 다른 PC나 폰에서 바뀐 메모가 있으면 그것만 받습니다. 앱을 켤 때와 탐색기를 열 때도 확인합니다.
- **창 배치는 PC마다 따로입니다.** 창 위치·크기·표시 여부·접힘 상태는 동기화하지 않습니다. 본문·제목·색·폴더 같은 내용만 동기화합니다.
- **설정도 함께 씁니다.** 어느 기기에서나 같아야 자연스러운 설정은 드라이브의 `_settings.json` 한 파일로 주고받습니다. 한 PC에서 바꾸면 다음 동기화 때 다른 PC에 반영되고, 폰 화면도 폴더 순서와 새 메모 기본값을 여기서 읽습니다. 더 나중에 바꾼 쪽이 남습니다.

  | 함께 쓰는 설정 | PC마다 따로 두는 설정 |
  |---|---|
  | 디자인 스타일과 색 테마, 폴더 목록·순서·표시 방식, 새 메모 기본값(색·글꼴·크기·불투명도 등), 단축키, 자동 저장·자동 잠금 시간, 휴지통 보관 기간, 변경 후 동기화까지 기다리는 시간 | 메모 저장 폴더, 동기화 주소와 접근 암호, 동기화 켜기/끄기, Windows 자동 실행, 창 위치와 크기, 탐색기 크기 고정 |

  동기화 주소와 접근 암호는 그것이 있어야 이 파일을 받을 수 있으므로 새 PC에서는 직접 넣어야 합니다. 그 뒤로는 나머지 설정이 따라옵니다.
- **충돌:** 두 PC에서 같은 메모를 각각 고쳤으면 더 최근에 고친 쪽이 남습니다. 내려받은 내용이 이 PC의 수정을 덮게 될 때는 이 PC의 것을 `(충돌 사본)` 메모로 따로 남깁니다.
- **삭제:** 한 PC에서 지운 메모는 다른 PC에서도 휴지통으로 갑니다. 오프라인이어서 드라이브에서 못 지운 것은 다음 동기화 때 다시 시도합니다.
- **안전장치:** 드라이브 목록에서 메모가 한꺼번에 절반 넘게 사라져 보이면 드라이브 쪽 문제로 보고 삭제를 반영하지 않습니다.

### 알아 둘 한계

- **접근 암호를 설정하세요.** 스크립트에 `ACCESS_TOKEN`을 넣지 않으면 웹 앱 주소를 아는 사람은 누구나 암호를 걸지 않은 메모를 읽고 쓸 수 있습니다. 접근 암호를 넣었더라도 주소와 암호는 공유하지 말고, 민감한 메모에는 메모 암호를 거세요.
- **최신본은 기기의 시계로 판단합니다.** 기기들의 시계가 크게 어긋나면 판단이 틀릴 수 있습니다. 시계를 자동 동기화로 두세요.
- **드라이브 휴지통은 자동으로 비우지 않습니다.** 지운 메모는 드라이브의 `Memos/trash_bin` 폴더에 남습니다.

### 설정 방법

PC 앱의 환경설정 → 구글 동기화 탭 → `설정 방법 보기 (GitHub)` 버튼을 누르면 이 대목이 열립니다.
필요한 파일은 이 저장소의 [mobile/Code.gs](mobile/Code.gs)(동기화 저장소 겸 모바일 화면 서버)와 [mobile/Index.html](mobile/Index.html)(모바일 화면) 두 개입니다.

**1단계. 구글 앱스 스크립트 만들기**

1. [구글 드라이브](https://drive.google.com) → 새로 만들기 → 더보기 → Google Apps Script를 엽니다.
2. `Code.gs`의 기존 내용을 지우고, 이 저장소의 [mobile/Code.gs](mobile/Code.gs) 내용을 붙여 넣습니다.
3. 파일 추가(+) → HTML을 눌러 이름을 `Index`로 만들고, [mobile/Index.html](mobile/Index.html) 내용을 붙여 넣습니다. (모바일 화면을 쓰지 않더라도 넣어 두세요)

**2단계. 접근 암호 정하기 (권장)**

1. 왼쪽 톱니바퀴(프로젝트 설정) → 스크립트 속성 → 속성 추가를 누릅니다.
2. 속성 이름에 `ACCESS_TOKEN`, 값에 원하는 암호를 넣습니다. 이름은 대문자 그대로, 앞뒤에 빈칸 없이 넣습니다.
3. 아래쪽의 **스크립트 속성 저장** 버튼을 누릅니다. 이 버튼을 누르지 않으면 저장되지 않습니다.

이 값을 넣으면 그 암호를 아는 기기만 메모를 읽고 쓸 수 있습니다. 속성은 저장하는 즉시 적용되며 다시 배포할 필요는 없습니다.

**적용됐는지 확인하기:** PC 브라우저에서 웹 앱 주소 끝에 `?action=list`를 붙여 엽니다. `Unauthorized`가 나오면 적용된 것이고, 파일 목록이 나오면 아직 적용되지 않은 것입니다.

**3단계. 웹 앱으로 배포하기**

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴에서 **웹 앱**을 고르고, 실행 계정은 **나**, 액세스 권한은 **모든 사용자**로 두고 배포합니다.
3. 만들어진 **웹 앱 URL**을 복사합니다.

**4단계. PC 앱에 연결하기**

1. 트레이 아이콘 우클릭 → **환경설정** → 구글 동기화 탭을 엽니다.
2. `구글 드라이브 동기화 활성화`를 켜고 URL을 붙여 넣습니다.
3. 2단계에서 암호를 정했다면 `동기화 접근 암호`에 같은 값을 넣습니다.
4. 연결 테스트 버튼으로 확인한 뒤 저장합니다.

### 스크립트를 고쳤을 때 (다시 배포)

쓰던 프로젝트를 고쳐서 다시 배포합니다. 주소는 그대로 유지됩니다.

1. [script.google.com](https://script.google.com)에서 쓰던 프로젝트를 엽니다.
2. 바뀐 파일(`Code.gs`, `Index`)의 내용을 새 것으로 바꿔 붙이고 저장합니다.
3. **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 누릅니다. "새 배포"를 누르면 주소가 바뀌니 주의하세요.
4. PC 앱에서 동기화가 되는지, 브라우저에서 웹 앱 주소를 열었을 때 모바일 화면이 뜨는지 확인합니다.

3.0.0 이하에서 올라오면서 접근 암호를 처음 넣는 경우, 스크립트에 `ACCESS_TOKEN`을 넣은 뒤 곧바로 PC 앱 환경설정에도 같은 값을 넣으세요. 그 사이에는 PC 앱 동기화가 실패합니다. 같은 메모를 쓰는 PC가 여러 대라면 모두 3.1.0으로 올려야 합니다. 3.0.0 이하의 PC 앱은 접근 암호를 보낼 수 없습니다.

### 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 접근 암호를 넣었는데도 암호 없이 접속된다 | 스크립트 속성에서 **스크립트 속성 저장**을 눌렀는지, 이름이 정확히 `ACCESS_TOKEN`인지, 지금 쓰는 웹 앱 주소의 프로젝트에 넣었는지 확인합니다. `?action=list`로 적용 여부를 볼 수 있습니다. |
| PC 앱 연결 테스트가 실패한다 | URL과 `동기화 접근 암호`가 맞는지 확인합니다. 접근 암호가 틀려도 실패로 표시됩니다. |
| 스크립트를 고쳤는데 반영되지 않는다 | **배포 관리 → 수정 → 새 버전**으로 다시 배포했는지 확인합니다. 저장만으로는 반영되지 않습니다. |
| 다시 배포했더니 PC 앱 동기화가 안 된다 | "새 배포"를 눌러 주소가 바뀐 경우입니다. 새 주소를 PC 앱 환경설정에 다시 넣습니다. |
| 폰에서 접근 암호를 매번 묻는다 | [접근 암호를 매번 묻는다면](#접근-암호를-매번-묻는다면)을 보세요. |
| 폰에서 고친 내용이 PC에 안 보인다 | PC 앱에서 동기화 버튼을 누릅니다. 그 메모를 PC에서도 고치던 중이었다면 `(충돌 사본)` 메모가 생겼는지 확인합니다. |

## 📱 모바일에서 쓰기 (아이폰·아이패드·안드로이드)

PC 앱은 Windows 전용이지만, 같은 메모를 폰의 브라우저에서 읽고 쓸 수 있습니다. 위에서 배포한 **웹 앱 URL을 폰의 브라우저로 열면** 모바일 화면이 뜹니다. 별도 설치나 서버는 필요 없습니다.

### 시작하기

1. 폰에서 웹 앱 URL을 엽니다. (PC에서 자신에게 메일이나 메신저로 보내면 편합니다)
2. 접근 암호를 정해 두었다면 한 번 입력합니다.
3. 아이폰·아이패드는 사파리의 공유 버튼 → **홈 화면에 추가**를 누르면 앱처럼 아이콘으로 열 수 있습니다.

### 접근 암호를 매번 묻는다면

아이폰·아이패드의 사파리는 이 화면이 기억해 둔 값을 오래 유지해 주지 않을 수 있습니다. 그럴 때는 접근 암호를 주소에 붙여 둡니다.

1. 웹 앱 주소 끝에 `?k=접근암호`를 붙입니다. 예: `https://script.google.com/macros/s/.../exec?k=내암호`
2. 사파리에서 그 주소를 엽니다. 암호를 묻지 않고 목록이 뜹니다.
3. 그 상태에서 공유 버튼 → **홈 화면에 추가**를 누릅니다. 전에 만든 아이콘은 지웁니다.

이 주소에는 접근 암호가 들어 있으니 다른 사람에게 보내지 마세요. 폰을 잃어버렸거나 주소가 새어 나갔다면 스크립트 속성의 `ACCESS_TOKEN` 값을 바꾸면 기존 주소는 바로 막힙니다. (그 뒤 PC 앱과 폰에 새 값을 넣습니다)

### 할 수 있는 것

- 메모 목록, 제목·내용 검색, 전체/일반/코드/즐겨찾기 필터, 해시태그
- 새 메모(일반·코드) 만들기, 제목·본문 수정, 삭제
- **폴더:** 왼쪽 위의 폴더 버튼(지금 폴더 이름이 적혀 있음)을 누르면 폴더 목록이 열립니다. 폴더 순서는 PC에서 정한 그대로이고 폴더마다 메모 개수가 보입니다. 메모를 폴더로 옮기거나 새 폴더를 만들 수 있습니다. 아이패드처럼 넓은 화면에서는 폴더 목록이 항상 펼쳐져 있습니다.
- 즐겨찾기, 메모 색 바꾸기
- **체크리스트:** 편집 화면 위의 체크 버튼을 누를 때마다 커서가 있는 줄이 `상자 없음 → ☐ → ☑ → ☐`로 바뀝니다. 체크리스트 줄 끝에서 줄을 바꾸면 다음 줄도 상자로 시작합니다.
- **알림 보기:** 알림이 걸린 메모는 목록에 `⏰`가 붙고, 메모를 열면 아래쪽에 알림 시각이 보입니다.
- 암호 메모 열기·수정, 암호 걸기, 암호 제거

폰에서 고친 내용은 PC 앱의 다음 동기화 때 반영되고, PC에서 고친 내용은 폰에서 새로 고침하면 보입니다.

### 알아 둘 점

- **서식이 있는 메모:** 굵게·색·목록 같은 서식이 든 메모는 글자만 보여 줍니다. 폰에서 본문을 고쳐 저장하면 서식은 사라지고 글자만 남습니다. 즐겨찾기나 색, 폴더만 바꾸면 서식은 그대로입니다.
- **암호 메모:** PC 앱과 같은 방식으로 폰 안에서 암호화·복호화합니다. 풀린 본문은 서버로 보내지 않고 기기에도 저장하지 않습니다. 폰에서 새로 건 암호에는 관리자 복구 정보가 들어가지 않으며, PC 앱에서 한 번 열어 저장하면 추가됩니다.
- **동시에 고친 경우:** 폰에서 메모를 연 뒤 다른 기기가 그 메모를 고쳤으면, 저장할 때 알려 주고 사본으로 저장할지 덮어쓸지 묻습니다.
- **인터넷 연결이 필요합니다.** 연결이 없으면 마지막으로 받아 둔 목록을 볼 수는 있지만 저장할 수 없습니다.
- **PC 앱에서만 되는 것:** 휴지통 보기·복원, 폴더 순서 바꾸기·이름 바꾸기·삭제, 알림 걸기·바꾸기와 알림 울리기, 이전 내용 되돌리기, 화면에 떠 있는 메모, 접기, 전역 단축키.
- **새 메모 기본값:** 폰에서 만드는 메모의 색과 코드 메모 기본 언어는 PC 환경설정에서 정한 값을 따릅니다.
- 주소를 열면 화면 위에 구글이 붙이는 안내 띠가 보일 수 있습니다. 개인이 만든 스크립트에 붙는 것으로 정상입니다.

### PC에서 미리 써 보기

구글에 올리지 않고 PC 브라우저에서 모바일 화면을 시험해 볼 수 있습니다. 견본 메모로 동작하며 실제 메모는 건드리지 않습니다. (견본 암호 메모의 암호는 `1234`)

```bash
python tools/mobile_dev_server.py
```

실행한 뒤 브라우저에서 `http://127.0.0.1:8765`를 엽니다.

## ⚙ 환경설정

메모 탐색기의 `미리보기` 글자 왼쪽에 있는 톱니바퀴 버튼(다시 누르면 닫힘), 또는 트레이 아이콘 우클릭 → 환경설정으로 엽니다. 환경설정은 따로 뜨는 창이 아니라 **탐색기 옆에 펼쳐지는 패널**입니다. 폴더 사이드바처럼 탐색기 창이 그만큼 옆으로 늘어나고(오른쪽에 자리가 없으면 왼쪽), 탐색기 본래 영역의 크기와 자리는 그대로입니다. 탐색기가 닫혀 있을 때 트레이에서 열면 탐색기와 함께 열리고, 탐색기를 닫거나 숨기면 패널도 닫힙니다.

**저장하지 않은 변경:** 값을 바꾸고 아직 저장하지 않았으면 `설정 저장` 버튼에 `●`가 붙습니다. 그 상태에서 패널이나 탐색기를 닫거나 앱을 끝내려 하면 `저장하고 닫기` / `저장 안 함` / `취소` 중에서 고르게 묻습니다. 바꿨다가 원래대로 되돌린 경우에는 묻지 않습니다. Windows를 로그오프하거나 종료할 때는 물을 수 없어 저장하지 않은 변경이 그대로 사라집니다.

화면을 스크롤하다 옵션이 바뀌지 않도록, 값은 휠이 아니라 클릭으로만 바뀝니다.

| 탭 | 설정할 수 있는 것 |
|---|---|
| 일반 설정 | 폴더 표시 방식, Windows 시작 시 자동 실행, 자동 저장 대기 시간, 암호 메모 자동 잠금 시간, 휴지통 보관 기간, 한/영 자동 변환, 새 메모 기본값(고정·행 번호·줄노트 배경), 알림 설정의 빠른 선택 세 개, 사용 안내 메모 만들기 |
| 구글 동기화 | 설정 방법 보기(이 문서의 [설정 방법](#설정-방법)을 브라우저로 엶), 동기화 켜기/끄기, GAS URL과 연결 테스트, 동기화 접근 암호, 메모 저장 폴더, 변경 후 동기화까지 기다리는 시간 |
| 테마 & 서식 | 디자인 스타일, 라이트/다크 색 테마, 새 메모 기본 색·글꼴·크기·불투명도, 접은 메모 높이, 코드 메모 기본 언어·테마, 탐색기 크기와 크기 고정 |
| 단축키 설정 | 전역 단축키를 다른 프로그램을 쓰는 중에도 받을지, 모든 단축키 변경, 기본값으로 초기화. 다른 기능이 쓰던 단축키를 고르면 알려 주고 그쪽 단축키를 비웁니다(같은 단축키를 두 기능에 걸 수 없음). |

**탐색기 크기 고정:** 배율이 다른 모니터 사이를 옮길 때 탐색기 크기가 변하는 환경이라면 `탐색기 크기 고정`을 켜세요.

## 💾 데이터가 저장되는 곳

실행 파일과 따로 저장되므로, 실행 파일을 바꾸거나 옮겨도 그대로 남습니다.

| 내용 | 위치 |
|---|---|
| 메모 | 환경설정에서 정한 폴더 (기본 `~/.memoit_custom/memos`). 메모 하나가 `{id}.json` 파일 하나입니다. |
| 휴지통 | 메모 폴더 안의 `trash_bin` |
| 이전 내용 (변경 기록) | 메모 폴더 안의 `history_bin`. 메모 하나에 `{id}.json` 하나이며 동기화하지 않습니다. |
| 설정 | `~/.memoit_custom/settings.json` |
| 동기화 기록 | `~/.memoit_custom/sync_state.json`, `pending_deletes.json` |
| 공유 설정 | 드라이브의 `Memos/_settings.json` (동기화를 켠 경우. 기기끼리 함께 쓰는 설정만 들어 있음) |
| 오류 기록 | `~/.memoit_custom/error.log` (1MB를 넘으면 이전 기록 하나만 남기고 새로 시작) |

`~`는 사용자 폴더(`C:\Users\이름`)입니다.

**본문 저장 형식**

- 서식이 없는 메모와 코드 메모는 순수 텍스트로 저장합니다.
- 굵게·목록·색 같은 서식을 쓴 메모만 HTML로 저장합니다.
- 암호 메모는 본문만 암호문으로 저장합니다.

백업은 메모 폴더를 통째로 복사해 두면 됩니다.

## 🆕 3.2.2에서 달라진 점

3.2.1 대비입니다. 암호 메모의 변경 기록에 관한 보안 수정과, 전체 코드 점검에서 나온 문제들의 수정입니다. 메모 파일 형식은 그대로입니다.

### 고친 문제

- **암호를 걸기 전의 내용이 변경 기록에 평문으로 남던 문제.** 메모에 암호를 걸어도, 걸기 직전의 본문과 그 전에 쌓인 기록이 메모 폴더의 `history_bin`에 암호화되지 않은 채 남아 있었습니다. 이제 암호를 거는 순간 그 메모의 기록을 같은 암호로 잠급니다.
- **기록으로 되돌리면 암호 메모가 경고 없이 일반 메모가 되던 문제.** 암호를 걸기 전의 기록으로 되돌리면 암호가 풀린 채 저장되고 동기화됐습니다. 이제 되돌려도 메모의 잠금 상태와 암호는 그대로입니다.
- **미리보기에서 체크 상자를 한 번 누르면 서식이 모두 사라지던 문제.** 굵게·색·목록이 든 메모도 이제 미리보기에서 체크하면 서식을 지킨 채 그 상자만 바뀝니다. 미리보기에서 글자를 고쳐 서식이 사라지는 경우에는 그 사실을 알려 줍니다.
- **모니터가 여러 대일 때 접고 펴면 기억한 자리로 돌아가지 못하던 문제.** 펼친 자리와 접은 자리가 서로 다른 모니터에 있어도 각자 기억한 자리로 돌아갑니다.
- **체크해 둔 메모가 목록이 다시 그려질 때 풀리던 문제.** 동기화가 끝나거나 열어 둔 메모가 저장되어도 체크가 유지됩니다.
- **다른 기기에서 설정이 도착하면 환경설정에서 고치던 값이 묻지 않고 덮이던 문제.** 고치던 값이 있으면 덮지 않고 알려 주기만 합니다.
- **긴 메모에서 글자를 칠 때마다 본문 전체를 여러 번 훑던 문제.** 체크 상자가 없는 메모는 훑지 않고, 있는 메모도 한 번만 훑습니다.
- 폴더 사이드바가 열린 채로 환경설정을 저장하면 탐색기 위치가 그만큼 왼쪽으로 치우쳐 저장되던 문제.
- 메모를 닫아도 옆에 붙여 열었던 패널이 숨은 채 남던 문제.

### 달라진 동작

- 암호를 바꾸면 기록도 새 암호로 다시 잠깁니다. 예전 암호를 따로 기억할 필요가 없습니다.
- 암호를 없애면 그 암호로 잠겨 있던 기록도 함께 풀립니다.
- 열려 있는 암호 메모의 기록은 암호를 다시 넣지 않아도 보입니다.
- 잠겨 있는 암호 메모는 먼저 잠금을 풀어야 되돌릴 수 있습니다. 전에는 내용을 보지 않고도 되돌릴 수 있었습니다.
- 여러 메모를 지울 때 확인 화면에 지워질 메모의 제목이 보입니다.
- 빠른 검색은 암호 메모가 열려 있는 중에도 내용으로 찾거나 보여 주지 않습니다. (제목으로는 찾습니다)
- 동기화가 이미 설정된 PC에서는 사용 안내 메모를 자동으로 만들지 않습니다. 다른 기기에서 고치거나 지운 안내 메모를 덮거나 되살리지 않기 위해서이며, 환경설정에서 직접 만들 수 있습니다.
- 휴지통을 보는 중에는 `Delete` 키가 동작하지 않습니다.

### 내부 정리

동작은 그대로이고 코드 구조만 바꾼 것입니다.

- **색을 정하는 곳을 한곳으로.** 체크 상자, 암호 입력 가림막, 메모 옆 패널, 미리보기가 저마다 색을 계산하던 것을 `modern_style`의 색 묶음에서 받아 쓰도록 바꿨습니다.
- **메모 창의 위치·크기 규칙을 따로.** 접고 펼 때의 자리 계산을 `memo_geometry.py`로 옮겨, 창을 띄우지 않고 숫자만으로 테스트할 수 있게 했습니다.
- **메모 탐색기를 역할별로 나눔.** 2천 줄 가까이 되던 `memo_explorer.py`에서 폴더, 창 크기·옆 패널, 미리보기, 여러 메모 고르기를 각각 `explorer_folders.py`, `explorer_panels.py`, `explorer_preview.py`, `explorer_selection.py`로 옮겼습니다. 폴더 사이드바와 환경설정 패널을 열 때 창을 옆으로 늘리던 같은 코드 두 벌도 하나로 합쳤습니다.
- **창 안 입력 쪽 모듈의 경계 정리.** 대화상자와 가림막이 서로를 불러 쓰던 것을 한 방향(`live_settings` → `input_panels` → `overlay` → `themed_dialog`)으로 풀었습니다. 입력 화면(여러 칸 입력·버튼 고르기·색 고르기)은 `input_panels.py`로, 설정을 읽는 통로는 `live_settings.py`로 옮기고, 탐색기의 가림막까지 담고 있어 이름이 맞지 않던 `lock_overlay.py`는 `overlay.py`로 바꿨습니다.
- **환경설정의 불러오기·모으기를 표 하나로.** 화면의 칸 하나가 설정값 하나와 그대로 짝지어지는 설정 21가지를 `SettingsWindow.FIELDS` 표에 모아, 불러올 때와 저장할 때 같은 표를 쓰게 했습니다. 이런 설정을 새로 넣을 때 두 곳을 따로 고치다 한쪽을 빠뜨리는 일이 없어집니다. 저장된 값이 고를 수 있는 항목에 없으면 기본값을 고릅니다.
- **테스트를 주제별 파일로.** 2,500줄짜리 `test_features.py`를 알림·체크리스트·이전 내용·암호 메모·탐색기·환경설정·대화상자·메모 창·사용 안내·빠른 검색 파일로 나누고, 작업한 순서대로 묶여 주제가 섞여 있던 테스트를 주제에 맞는 묶음으로 옮겼습니다. 공용 준비는 `tests/support.py`로 뺐고, 파일 하나만 따로 돌릴 수도 있습니다(`python tests/test_reminders.py`).
- **동기화가 화면을 직접 부르지 않게.** 동기화 쪽(`core`)이 탐색기 토스트와 트레이 알림을 직접 띄우고, 안내 문구에 "동기화 완료"가 들어 있는지로 목록을 새로 고칠지 정하던 것을 고쳤습니다. 이제 동기화는 결과 값(바뀜·바뀐 것 없음·끝내지 못함)만 넘기고, 어떻게 보여 줄지는 `UIManager.show_sync_result`가 정합니다.
- **화면을 만드는 긴 함수를 구역별로.** 환경설정(594줄), 탐색기(287줄), 메모 창(275줄), 알림 설정(153줄)의 화면을 한 함수에서 만들던 것을 탭·줄·묶음별 함수(`_build_general_tab`, `_build_header`, `_build_title_row` 등)로 나눴습니다. 내용은 그대로 옮기기만 했습니다.
- **`SyncManager`를 역할별로 나눔.** 1,100줄 가까이 되던 `sync_manager.py`에서 암호 메모, 이전 내용, 휴지통을 각각 `memo_password.py`, `memo_history.py`, `memo_trash.py`로 옮겼습니다. `sync_manager.py`에는 설정, 메모 파일 읽고 쓰기, 알림 목록, 동기화 실행이 남습니다.
- **본문 편집기의 키 처리를 키 종류별로.** 215줄짜리 `keyPressEvent`를 여러 커서, 줄 옮기기, 코드 메모의 괄호 짝·들여쓰기, Tab 처리 함수로 나누고, 이 키 동작을 확인하는 테스트 10개를 새로 넣었습니다.
- **메모 창을 역할별로 나눔.** `memo_window.py`에서 접기·펴기, 저장·제목 바꾸기, 찾기·바꾸기, 우클릭 메뉴를 각각 `memo_rollup.py`, `memo_saving.py`, `memo_find.py`, `memo_menu.py`로 옮겼습니다(1,585줄 → 1,067줄).

### 올릴 때 할 일

- **이미 암호를 걸어 둔 메모가 있다면 한 번씩 열어 주세요.** 3.2.0~3.2.1에서 암호를 건 메모는 걸기 전의 내용이 `history_bin`에 평문으로 남아 있을 수 있습니다. 이 버전에서 그 메모의 잠금을 한 번 풀면 그때 남아 있던 평문 기록이 잠깁니다. 열기 전까지는 그대로 남아 있습니다.
- 메모 폴더를 통째로 복사해 둔 백업이 있다면, 그 백업의 `history_bin`에는 평문이 그대로 들어 있습니다. 필요하면 백업을 다시 만드세요.
- 파일을 다시 써도 디스크에서 예전 내용이 물리적으로 지워지는 것까지 보장하지는 못합니다.

## 🆕 3.2.1에서 달라진 점

3.2.0 대비입니다. 메모 파일 형식은 그대로입니다. 3.2.0의 새 기능을 다듬고, 따로 뜨던 창들을 한 창 안으로 모았습니다.

### 추가

- **사용 안내 메모:** 처음 실행하면 사용법을 적은 메모 세 개가 만들어집니다. 환경설정에서 다시 만들 수 있습니다. → [처음 실행했을 때](#처음-실행했을-때)
- **취소선:** 서식 줄의 `S` 버튼으로 선택한 글자에 줄을 긋습니다.
- **글꼴 검색·크기 입력:** 글꼴은 이름의 일부를 적어 찾고, 크기는 숫자를 직접 적을 수 있습니다. 칸 옆의 `▾`로 목록을 엽니다.
- **형광펜 사용자 지정색:** 원하는 색을 직접 골라 칠합니다.
- **미리보기 우클릭 메뉴:** 메모 열기, 체크리스트, 복사·붙여넣기, 알림 설정, 이전 내용 보기.
- **알림 설정:** 매주는 요일을, 매월은 날짜를 여러 개 고를 수 있습니다. 시간은 숫자로 적고 오전/오후 또는 24시간으로 봅니다. 빠른 선택 버튼 세 개를 환경설정에서 정합니다. 크론식에는 칸 설명과 누르면 입력되는 예시가 붙었습니다. → [알림](#알림)
- **암호 메모의 이전 기록 확인:** 기록을 고르고 그때 쓰던 암호를 넣으면 되돌리기 전에 내용을 볼 수 있습니다.
- **동기화 설정 방법 링크:** 환경설정 → 구글 동기화 탭의 버튼으로 이 문서의 [설정 방법](#설정-방법)을 엽니다.
- **탐색기:** `미리보기` 왼쪽에 환경설정을 열고 닫는 버튼이 생겼고, 목록에서 `Delete` 키로 고른 메모를 지울 수 있습니다.
- **단축키를 받는 범위:** 새 메모·탐색기 열기 같은 전역 단축키를 어디서나 받을지(기본), 메모 탐색기나 메모 창이 앞에 있을 때만 받을지 고를 수 있습니다. → [전역 단축키](#전역-단축키)

### 달라진 동작

- **창을 따로 띄우지 않음:** 확인·이름 입력·암호·색 고르기는 부른 창(메모·탐색기) 안에서 묻고, 알림 설정과 이전 내용은 메모 옆에 붙어서 열립니다. Windows 기본 창은 파일·폴더 선택에만 남았습니다. "저장했습니다" 같은 알림은 그 창 안의 토스트로 보여 줍니다.
- **환경설정:** 따로 뜨는 창이 아니라 탐색기 옆에 펼쳐지는 패널로 열립니다. 탐색기와 한 창이며, 탐색기를 닫으면 함께 닫힙니다. 저장하지 않은 변경이 있으면 닫기 전에 저장할지 묻습니다. 트레이에서 환경설정을 열면 탐색기도 함께 열립니다.
- **체크리스트:** 글자 대신 네모 상자로 그려지고 끝낸 줄에는 취소선이 그어집니다. 진행 표시는 남은 일이 있으면 `☐ 2/5`, 다 끝내면 `☑ 5/5`입니다. 미리보기에서도 체크할 수 있고, 상자는 `Backspace` 한 번에 지워집니다. 암호 메모는 탐색기에 진행 표시를 내지 않습니다.
- **접은 메모와 펼친 메모:** 위치와 크기를 서로 따로 기억합니다. 접으면 항상 접어 두었던 자리로 돌아갑니다. (전에는 펼친 메모를 옮긴 뒤 접으면 옮긴 자리에서 접혔습니다)
- **암호 메모:** 암호는 메모 한가운데에서 묻습니다. 잠긴 메모는 암호 입력용 크기로 뜨고 암호를 넣으면 원래 크기로 돌아갑니다. 탐색기에서 열 때 암호를 따로 묻지 않습니다. 접어 둔 암호 메모는 제목 왼쪽에 자물쇠가 보입니다.
- **알림이 울릴 때:** 앱의 알림 창만 뜨고 Windows 알림은 뜨지 않습니다. 암호 메모는 내용 대신 `🔒 암호 메모`만 보입니다.
- **불릿·번호 목록:** 맨 앞에서 `Backspace` 한 번에 목록 표시와 들여쓰기가 함께 지워집니다.
- **환경설정:** `폴더 표시 방식`이 `테마 & 서식` 탭에서 `일반 설정` 탭 맨 위로 옮겨졌습니다. 다른 기능이 쓰던 단축키를 고르면 알려 주고 그쪽 단축키를 비웁니다.

### 고친 문제

- 탐색기에서 체크 상자를 하나씩 눌러 여러 메모를 고르면 앞의 체크가 풀려, 여러 개를 한 번에 지울 수 없던 문제. 여러 줄을 고른 뒤 우클릭 삭제가 한 개만 지우던 문제.
- 폴더 이름이 길거나 폴더가 많으면 탐색기가 강제로 넓어지던 문제. (긴 이름은 줄여 보여 주고, 드롭다운은 사이드바의 폴더 버튼과 같은 너비를 씁니다)
- 암호 메모를 접고 펼 때 접은 메모의 너비가 달라지던 문제. (암호 입력용 크기가 접은 너비로 저장되던 것, 자물쇠 아이콘 때문에 옆으로 늘어나던 것)
- 접은 암호 메모를 폈을 때 암호 칸이 보이지 않던 문제.
- 체크 상자가 있는 글자를 선택하거나 더블클릭하면 원래 글자(`☐`)가 네모 위에 겹쳐 보이던 문제.
- 알림이 앱의 알림 창과 Windows 알림으로 두 번 뜨던 문제.
- 메모 창에 저장 대기 중인 입력이 있을 때 탐색기 미리보기에서 고친 내용이 저장되지 않던 문제.
- 미리보기에서 고친 뒤 수정일시가 다른 표기(`261011.0830`)로 보이던 문제.
- 글꼴 칸을 닫은 뒤 메모 제목이 선택된 것처럼 보이던 문제.
- 형광펜의 '사용자 지정' 색이 정해진 색만 돌아가며 칠하던 문제.

### 올릴 때 할 일

- 폰에서 체크 상자를 한 번에 지우는 동작과 알림 표시(`매주 월·수` 등)를 쓰려면 구글 앱스 스크립트의 `Index.html`을 [mobile/Index.html](mobile/Index.html)로 바꿔 다시 배포합니다. `Code.gs`는 바뀌지 않았습니다. → [스크립트를 고쳤을 때](#스크립트를-고쳤을-때-다시-배포)
- 3.2.0에서 암호 메모를 잠근 채 처음 접어, 접은 메모가 좁게(340) 굳은 경우에는 접은 상태에서 너비를 한 번 조절해 주세요. 그 뒤로는 유지됩니다.

- **쌓아 둔 접은 메모 펴기:** 쌓인 줄 옆에 펼쳐지고, 옮기지 않고 다시 접으면 원래 자리로 돌아갑니다.

### 달라진 동작

- **동기화 방식:** 정해진 간격마다 돌던 동기화를, 바뀐 것이 있을 때만 바뀐 메모만 다루는 방식으로 바꿨습니다. 환경설정의 `동기화 주기`는 `변경 후 동기화까지 기다리는 시간`이 됐습니다.
- **수정일시:** 본문·제목을 고쳤을 때만 바뀝니다. 전에는 고친 것 없이 저장해도 바뀌었습니다. 폴더·즐겨찾기·색 변경은 수정일시를 건드리지 않고 동기화됩니다.
- **탐색기 제목 줄:** 왼쪽에 폴더 버튼과 라이트/다크 버튼, 가운데에 `Memos`, 오른쪽 끝에 창 버튼을 두었습니다.
- **환경설정 창:** Windows 기본 제목 줄 대신 탐색기처럼 자체 제목 줄을 씁니다.
- **화면 경계:** 탐색기와 환경설정 창이 화면 밖으로 나가거나 화면보다 커지지 않습니다. 탐색기는 보이는 테두리가 화면 끝에 딱 닿습니다.
- **Neo 디자인:** 메모 위쪽의 굵은 선을 없애고 네 변을 같은 옅은 테두리로 통일했습니다.
- **연결 테스트:** 접근 암호가 틀린 경우도 실패로 알려 줍니다.

### 올릴 때 할 일

- 구글 앱스 스크립트를 [mobile/Code.gs](mobile/Code.gs)와 [mobile/Index.html](mobile/Index.html)로 바꿔 다시 배포합니다. 예전 스크립트로도 PC 동기화는 되지만 모바일 화면과 접근 암호는 쓸 수 없습니다. → [스크립트를 고쳤을 때](#스크립트를-고쳤을-때-다시-배포)
- PC가 여러 대라면, 기준으로 삼을 PC에서 환경설정을 한 번 저장한 뒤 동기화하세요. 설정을 더 나중에 바꾼 PC의 설정이 다른 기기로 퍼집니다.

## 🆕 3.0.0에서 달라진 점

2.0.3 대비입니다.

### 보안

- **전체 암호와 로그인 화면을 없앴습니다.** 대신 메모마다 암호를 겁니다.
- **소스에 들어 있던 마스터 키를 없앴습니다.** 복구가 필요하면 공개키 방식의 관리자 복구 키를 씁니다.
- 내려받은 메모의 id를 검증해, 메모 폴더 밖에 파일이 써지지 않게 했습니다.

### 동기화

- 매번 전부 주고받던 방식에서 **바뀐 것만 주고받는 방식**으로 바꿨습니다.
- 양쪽에서 고친 메모를 내려받아 덮어쓸 때 **충돌 사본**을 남깁니다.
- 다른 PC에서 지운 메모가 이 PC에도 반영됩니다.
- 창 위치·크기·표시 여부를 동기화에서 뺐습니다.
- 업로드·삭제가 실패했는데 성공으로 처리되던 문제를 고쳤습니다.

### 메모 편집

- 자동 저장을 "마지막 입력 후 대기" 방식으로 바꿨습니다.
- 목록·들여쓰기를 다시 만들었습니다. (선택한 줄만 적용, 하위 목록, 줄별 들여쓰기, 최대 8단계)
- 코드 메모의 `Tab`이 실제 공백이 됐습니다.
- 글자 크기를 바꿔도 굵게·기울임이 유지됩니다.
- 서식 없는 메모를 HTML 대신 텍스트로 저장합니다. `<`, `>`가 들어간 글이 미리보기·검색에서 지워지던 문제도 함께 해결됐습니다.

### 화면

- 디자인을 새로 만들었습니다. (Modern / Neo, Mono 색 테마 추가, 모서리는 모두 각지게)
- 탐색기에서 암호를 관리할 수 있습니다.
- 즐겨찾기 아이콘을 잘리지 않는 별로 바꿨습니다.
- 환경설정과 메모 창의 콤보박스가 휠에 걸려 바뀌지 않습니다.
- 탐색기 크기 설정과 크기 고정 옵션을 추가했습니다.
- 정렬이 메모가 놓인 모니터 안에서 동작합니다.

### 시스템

- 중복 실행을 막습니다. 다시 실행하면 실행 중인 앱의 탐색기가 열립니다.
- 전역 단축키가 다른 프로그램으로 새지 않습니다.
- Windows 자동 실행 옵션이 실제로 등록·해제됩니다.
- 휴지통 자동 삭제(보관 기간)를 추가했습니다.
- 시작할 때 보이는 메모의 창만 만들어 시작이 빨라졌습니다.
- 아이콘이 고배율 화면에서 흐리지 않습니다.

## 🔄 2.x에서 업그레이드

메모 폴더와 설정은 그대로 이어서 씁니다. 다만 아래는 알아 두세요.

- **전체 암호화돼 있던 메모는 처음 읽을 때 평문으로 바뀝니다.** 숨겨야 할 메모는 업그레이드 후 다시 암호를 거세요.
- **첫 동기화는 한 번 느립니다.** 동기화 기록 형식이 바뀌어 모든 메모를 다시 비교합니다. 그 한 번은 다른 PC에서 지운 메모의 반영도 건너뜁니다.
- **다른 PC에서 처음 내려받는 메모는 숨겨진 채로 들어옵니다.** 탐색기에서 열면 됩니다.
- **단축키 기본값이 Alt 조합으로 바뀌었습니다.** 예전에 직접 바꿔 둔 단축키는 그대로 유지됩니다.
- **여러 PC를 쓴다면 모두 같은 버전으로 올리세요.** 2.x가 섞여 있어도 동작은 하지만, 2.x 쪽은 창 배치를 계속 올립니다.
